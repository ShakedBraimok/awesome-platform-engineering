# Awesome Platform Engineering [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome)
"Platform engineering is an emerging technology approach that can accelerate the delivery of applications and the pace at which they produce business value.

Platform engineering improves developer experience and productivity by providing self-service capabilities with automated infrastructure operations. Platform engineering is trending because of its promise to optimize the developer experience and accelerate product teams’ delivery of customer value."

(Lori Perri @ Gartner)

# Tools

## Developers Portals
- [Backstage](https://backstage.io/) — Open-source framework for building developer portals.
- [Port](https://www.getport.io/) — No-code internal developer portal and software catalog.
- [OpsLevel](https://www.opslevel.com/) — Internal developer portal focused on service maturity and cataloging.
- [Roadie.io](https://roadie.io/) — Managed, SaaS-based Backstage platform.
- [Cortex](https://www.cortex.io) — Internal developer portal for service grading and software catalogs.
- [Configure8](https://www.configure8.io/) — Developer portal for tracking services, environments, and costs.
- [Rely.io](https://www.rely.io/) — Internal developer portal with a focus on software cataloging and reliability.
- [Atlassian Compass](https://www.atlassian.com/software/compass) — Developer portal for tracking service health, ownership, and metadata.
- [CyCloid](https://www.cycloid.io/solutions/self-service-portal) — Platform engineering and self-service portal for DevOps teams.
- [Flanksource Mission Control](https://www.flanksource.com) — Kubernetes-centric dashboard and internal developer portal.
- [KubeStellar Console](https://github.com/kubestellar/console) — Multi-cluster Kubernetes management console with AI-powered insights, MCP integration, and real-time observability across edge and cloud clusters.

## Internal Developers Platforms
- [Humanitec](https://humanitec.com/) — Platform orchestrator for building custom Internal Developer Platforms (IDPs).
- [Mia Platform](https://mia-platform.eu/) — Developer platform for simplifying cloud-native application delivery.
- [GitHub as a Platform Engineering Platform](https://www.youtube.com/watch?v=B4ra4MWiZck) — Guide on leveraging GitHub features to create an IDP.
- [Qovery](https://www.qovery.com/) — Internal developer platform for automated cloud application deployments.
- [Torque by Quali](https://www.quali.com/torque/) — Environment-as-a-Service platform for orchestrating application environments.
- [Aptible](https://aptible.com/) — Compliance-focused platform-as-a-service for hosting cloud apps.
- [Nethopper.io](https://www.nethopper.io/) — Multicloud platform orchestration and application networking tool.
- [Harness](https://www.harness.io/) — Software delivery platform including internal developer portal capabilities.

## Workload Specification & Orchestration Frameworks
- [Score](https://score.dev/) — Open-source, developer-centric workload specification that decouples application architecture from the environment.
- [Kratix](https://www.kratix.io/) — Open-source framework for building custom Internal Developer Platforms (IDPs) using a marketplace and promise-based model.
- [Radius](https://radapp.io/) — Open-source, cloud-native application platform by Microsoft that simplifies application delivery and management.

## Platform Adoption & Migration
- [Velq](#) — Migration tool from legacy DevOps to Platform Engineering.

## Templating & Scaffolding
- [Cookiecutter.io](https://cookiecutter.io) — Command-line utility that creates projects from templates.
- [AWS Proton](https://aws.amazon.com/proton/) — Automated management service for container and serverless deployments.
- [Helm.sh](https://helm.sh/docs/chart_best_practices/templates/) — Package manager and templating engine for Kubernetes.

## Day2Day Self-Service Operations
- [ScriptKit - for local actions](https://www.scriptkit.com/) — Toolkit for writing and executing automation scripts locally.
- [Port - Self-Service Hub](https://www.getport.io/product/self-service) — Self-service developer actions engine inside Port.
- [Env0 - Managed Self-Service](https://www.env0.com/solutions/managed-self-service) — Automated management and self-service for cloud infrastructure.
- [Flanksource Mission Control](https://docs.flanksource.com/playbooks) — Kubernetes-native automated playbooks and actions.

## Infrastructure as Code & Control Planes
- [Terraform](https://www.terraform.io/) — Open-source infrastructure-as-code tool by HashiCorp using HCL.
- [Crossplane](https://www.crossplane.io/) — The cloud native control plane framework.
- [Pulumi](https://www.pulumi.com/) — Infrastructure-as-code platform using standard programming languages.
- [CloudFormation](https://aws.amazon.com/cloudformation/) — AWS-native service for modeling and setting up resources.
- [AWS CDK](https://aws.amazon.com/cdk/) — Cloud Development Kit for defining AWS infrastructure in code.
- [Terraform CDK](https://developer.hashicorp.com/terraform/cdktf) — Define Terraform infrastructure using standard programming languages.
- [Wing](https://www.wing.cloud/) — Programming language designed specifically for cloud applications.
- [OpenTofu](https://opentofu.org/) — Community-driven, open-source fork of Terraform.

## Policy as Code & Guardrails
- [Open Policy Agent (OPA)](https://www.openpolicyagent.org/) — General-purpose policy engine to enforce unified guardrails across the platform stack.
- [Kyverno](https://kyverno.io/) — Kubernetes-native policy engine for governance, security, and configuration validation.

## Secrets Management & Security
- [Infisical](https://infisical.com/) — Open-source secret management platform engineered specifically to optimize developer workflows and security.
- [Akeyless](https://www.akeyless.io/) — Secrets management SaaS platform offering vaultless encryption and automated secrets lifecycle.

## Monitoring & Alerting
- [Keep](https://www.github.com/keephq/keep) — Open-source alert management and orchestration platform.
- [Canary Checker](https://canarychecker.io) — Kubernetes-native synthetic monitoring and health checking tool.
- [KubeStellar Console](https://console.kubestellar.io) — Open source AI-powered multi-cluster Kubernetes dashboard with real-time observability.

## FinOps & Cloud Cost Management
- [Cloud Waste Scanner](https://cloud-waste-scanner.com) — Tool for identifying and eliminating cloud resource waste.
- [Infracost](https://www.infracost.io/) — Cloud cost estimates for Terraform inside pull requests, shifting FinOps left directly to developers.
- [Kubecost](https://www.kubecost.com/) — Real-time Kubernetes cost monitoring, allocation, and capacity management for platform teams.

## AI Platform Engineering & LLMOps
- [Aquifer-ai](https://aquifer-ai.dev) — Open source Context Lake for organization agents.
- [LiteLLM](https://litellm.ai/) — Call all LLM APIs using the OpenAI format (AI Gateway).
- [Langfuse](https://langfuse.com/) — Open source LLM engineering platform (Observability, Analytics, Prompt Management).
- [Portkey](https://portkey.ai/) — Enterprise AI gateway and observability platform for production LLM apps.
